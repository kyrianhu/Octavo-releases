Android 1.5.0（versionCode 17）

跟进 iPad 版 OctavoScore 1.5，手机、折叠屏和平板共用同一安装包。

- 阅读器底栏新增“工具”：节拍器、调音器、钢琴和演奏模式。演奏模式只留翻页、书签和调音器，屏幕常亮，可锁定防误触（按住锁解锁）。
- “阅读”里新增护眼显示，滑条无级调节纸面暖色；分享时可选是否包含标注，并可直接打印。
- 书签可以命名；长按标题查看文件信息；节拍器可在常用速度标记间跳。
- 标注：笔迹按颜色分图层，可只看某几种颜色；工具栏里可删除当前页原有的 PDF 标记。
- 资料库：文件夹以卡片显示，可逐级进入和返回；＋ 可导入 PDF、新建空白乐谱（六种谱纸）或新建文件夹。
- 节目单按勾选顺序排列，可分享为 .octavoset 文件并在 iPad 与 Android 之间导入。
- 设置：预设主题、16 种主题颜色和自定义颜色、资料库背景（内置壁纸或自己的照片）、资料库主页选项。
- 不再记录和上传崩溃信息；问题反馈改为在浏览器中打开预填的 GitHub 页面。

Android 8.0 及以上；沿用原有签名，可覆盖安装并保留数据。已在 API 35 手机和平板模拟器上检查，尚未在真机上测试。iCloud 云盘和录音暂未提供。
